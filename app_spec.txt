# 炸金花在线卡牌游戏 - 项目规格说明

## 项目概述
一款Python驱动的网页多人在线炸金花卡牌对战游戏，支持实时对战。

## 技术栈
- 后端: Python 3.x + Flask + Flask-SocketIO
- 前端: HTML/CSS/JavaScript
- 通信: WebSocket (Socket.IO)

## 核心功能

### 1. 房间系统
- 玩家创建房间，获得房间ID
- 其他玩家通过房间ID加入
- 房间内等待玩家准备

### 2. 游戏规则
- 每局使用标准52张扑克牌(无大小王)
- 每位玩家发3张牌
- 初始积分: 100点

### 3. 玩家操作
- **闷牌(跟牌)**: 未看牌时，投入1/2/4积分，首个玩家设置底注
- **看牌**: 查看自己手牌，标记为已看牌状态
- **跟牌(看牌后)**: 已看牌时，投入2X底注积分
- **弃牌**: 放弃本局，积分不返还
- **开牌(闷开)**: 未看牌，投入底注，选择对手比牌
- **开牌(明开)**: 已看牌，投入2X底注，选择对手比牌

### 4. 牌型大小(从大到小)
1. 豹子: 三张相同
2. 同花顺: 同花色顺子
3. 同花: 同花色非顺子
4. 顺子: 不同花色顺子
5. 对子: 两张相同
6. 单张: 无组合

### 5. 游戏结束
- 场上只剩1名未弃牌玩家
- 该玩家获得池中所有积分

## 页面布局
- 顶部: 房间信息、玩家昵称、当前积分
- 中间: 各玩家状态卡片、总积分池
- 右侧: 当前底注
- 底部: 手牌区、操作按钮
